## ❓ FAQ

**1. Do I need to run it as Administrator?**

No — administrator privileges are not required to use Valheim's in-game console.

**2. Can antivirus software flag item-spawning tools?**

Security software may flag third-party files based on their behavior or reputation. Review warnings carefully and use files only from sources you trust.

**3. Does it work on Windows 11?**

The reference guide is intended for Windows desktop users. The built-in Valheim console is a game feature; separate third-party software may have different requirements.

**4. How do I spawn an item in Valheim?**

Open the console, enable `devcommands` in a supported world, then enter `spawn [ItemName] [Amount]`. For example, `spawn Wood 50` creates 50 pieces of wood. [Command reference](https://valheimwiki.net/en/mechanics/console-commands)

**5. Can I use spawn commands on every server?**

No. Cheat commands are restricted on dedicated servers and are generally available in single-player or worlds you host yourself. Back up your world before experimenting with commands that can affect saved data. [Details](https://valheimwiki.net/en/mechanics/console-commands)
